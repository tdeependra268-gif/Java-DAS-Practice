# Java DSA Practice 🚀

Welcome to my **Java DSA Practice** repository! This repository contains my solutions and practice programs for Data Structures and Algorithms (DSA) using Java.

I created this repository to improve my problem-solving skills, understand important DSA concepts, and prepare for coding interviews and software engineering internships.

## 📚 Topics Covered

The repository is organized into folders based on different DSA topics.

| Topic | Description |
|---|---|
| Arrays | Array problems and operations |
| Backtracking | Recursion-based search and decision problems |
| Binary Search | Efficient searching algorithms |
| Binary Tree | Binary tree problems and traversals |
| Dynamic Programming | Optimization and overlapping subproblem techniques |
| Graph | Graph traversal and graph algorithms |
| HashMap | Key-value mapping and frequency counting |
| Heap (PriorityQueue) | Heap operations and priority-based problems |
| LinkedList | Linked list operations and problems |
| Queue | Queue operations and implementations |
| Sliding Window | Efficient subarray and substring problems |
| Stack | Stack operations and related problems |
| Strings | String manipulation and algorithmic problems |
| Two Pointer | Problems using two-pointer techniques |

## ▶️ How to Run a Java Program

1. Clone this repository:

   ```bash
   git clone https://github.com/tdeependra268-gif/project.git
   ```

2. Open the project in VS Code or IntelliJ IDEA.

3. Navigate to the topic folder and open a Java file.

4. Compile and run the program:

   ```bash
   javac Main.java
   java Main
   ```

   Replace `Main.java` with the actual filename if needed. The Java filename and public class name must match.
